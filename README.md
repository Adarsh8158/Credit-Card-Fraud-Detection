# 💳 Credit Card Fraud Detection

A Machine Learning project that detects potentially fraudulent credit card transactions using data analysis and classification techniques.

## 📌 Project Overview

Credit card fraud is a major problem in digital transactions. This project uses Machine Learning to identify whether a transaction is **legitimate or fraudulent** based on transaction-related features.

## 🎯 Objectives

* Analyze credit card transaction data
* Perform data cleaning and preprocessing
* Explore patterns using data visualization
* Train a Machine Learning classification model
* Evaluate model performance
* Predict fraudulent transactions

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Open `card.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells sequentially.
